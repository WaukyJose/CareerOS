# VS011.5 - Collector Robustness

## Objective

Improve collector HTTP reliability and isolate source failures.

## Scope

- Use a configurable 30-second default HTTP timeout.
- Send consistent User-Agent, Accept, and Accept-Language headers.
- Retry only transient network and HTTP failures.
- Record execution failure reasons, including timeouts.
- Continue running other collectors after one source fails.
- Add regression tests and documentation.

## Acceptance Criteria

- HTTP requests use the configured timeout and standard headers.
- Parsing, configuration, and permanent HTTP errors are not retried.
- Timeouts and transient HTTP/network failures are retried.
- A timed-out collector records its reason and does not stop later collectors.
- All tests pass.

## Status

Complete.
